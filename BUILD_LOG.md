# Build Log

How this site is built and maintained, and the judgment calls made along the way. Written because the process is arguably as on-brand as the content — a small, honest case study in directing AI-assisted engineering with real human checkpoints, not letting it run unsupervised.

## Stack and pipeline

- `index.php` is the single hand-edited source. `index.html` is generated by running `php -f index.php > index.html` — PHP's only job here is stripping `<?php /* ... */ ?>` dead-comment blocks left over from an earlier template; there's no other server-side dependency anywhere in the stack.
- The project showcase grid lives in `assets/js/main.js` (jquery-elastic-grid), not the PHP file.
- Deployed straight from git to both Netlify and Cloudflare Pages — no build step on either host.
- A GitHub Action (`.github/workflows/build-html.yml`) also regenerates `index.html` on push, though it's currently blocked by a PAT scope issue (pushing to `.github/workflows/*` needs the `workflow` scope, which the repo's token doesn't have yet).

## Tag taxonomy

Went through several real revisions before landing: started at 15 sprawling, inconsistent tags (`AI/ML`, `Python`, `LangGraph`, `AWS`, `Security`, `DevOps`, `RAG`, `Product`, `Web`, `ERP`, `CMS`, `Mobile app`, `UI/UX design`, `E-commerce`, `Trading`), which made the filter bar meaningless. Collapsed to 5 deliberate tags — **AI Engineering, AI Governance, Technical Leadership, Cloud/DevOps, Full-Stack Engineering** — chosen to map 1:1 onto five actual certifications rather than onto tech-stack keywords. Every project's tags were re-derived from what it actually demonstrates, not what's easiest to claim.

**A real bug found in the process:** the vendored `elastic_grid.js` plugin slugifies tag text into a CSS class with a plain `String.replace(' ','-')` — no `/g` flag, so it only replaces the *first* space. The original "Cloud & DevOps" tag has two spaces (around the `&`), so the class applied to project items and the class the filter button checked for silently diverged — the filter always returned zero results, no console error. Fixed by renaming to `Cloud/DevOps` (zero spaces) rather than patching the vendored plugin. Any future tag needs at most one space.

## Screenshots

Cover thumbnails follow the same convention the original template already used for its legacy projects (e.g. `dsj/front_thumb.PNG`, `erp/accounting_dashboard_thumb.PNG`) — a tight square close-up of the most visually distinctive real content, not a full-page overview. Full-page screenshots exist too, as the 2nd+ images in each card's gallery.

All screenshots are real, captured live via Playwright, not stock art or mockups:

- Two of the apps (Streamlit Community Cloud, Hugging Face Spaces) auto-sleep on their free tier after inactivity — capturing them meant clicking the wake/restart button and waiting 30–90s for a real boot, not just hitting the URL.
- Hugging Face Spaces embed the actual app in an iframe at `https://<user>-<space>.hf.space/`, separate from the `huggingface.co/spaces/...` page — interacting with the app (not just screenshotting the loading chrome) meant navigating to the embed URL directly.
- For Change Impact Assessor, rather than screenshot the empty input form and call it done, ran an actual sample assessment through to completion to capture the real governance gate firing — "HIGH risk — pending human sign-off" with live Acknowledge/Discard buttons, not a description of what it would do.
- One redaction: a scroll position on the Quant platform's public GitHub README happened to include a real IBKR account number (already public, in an already-public repo). Cropped it out of the portfolio screenshot anyway — the repo being public doesn't obligate the portfolio to amplify it. Small decision, but it's the same instinct the site's own "AI Governance Philosophy" section describes, applied to something as mundane as picking a screenshot's scroll position.

## Positioning

The header, About Me, and project ordering were rewritten mid-build to lead with AI governance rather than treat it as one of several co-equal pillars, in response to a real (and at the time undisclosed) job offer. Specific employer name and start date were deliberately kept off every file touched during that window — the site's copy changed to reflect a shift in priorities without leaking information that wasn't public yet.
